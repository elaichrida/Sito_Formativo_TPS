ù# Sito_Formativo_TPS
Creazione di un sito in cui si racconta il percorso degli alunni informatici dalla 1° alla 4°.

## Passaggi 
- Creazione repository
- Creazione container

- La mia storia al greppi

## Modalità di sviluppo

- 1 componente si occupa di reperire le informazioni. Inserirle in un file di supporto con i dati
- 1 componente si occupa di inserire le informazioni nel sito. Creazione dei file html
- 1 componente si occupa dello stile del sito. Strutturazione file css
